# v0.3.0

## Highlights

- Omakure is now a headless release: CLI, HTTP management API, and the
  machine-owned `node serve` service are the supported product surfaces.
- The first pre-1.0 headless release is deliberately breaking and removes the
  interactive terminal UI, theme subsystem, and directory Lua widgets.
- The release package is one platform binary with no workspace scripts, themes,
  widgets, or auxiliary UI assets.

## Breaking changes

- Removed no-argument TUI startup, TUI screens, forms, keybindings, widgets,
  snapshots, and TUI-only abstractions.
- Removed positional `omakure PATH` mode and its session-only scripts-root
  behavior. Use `--scripts-dir PATH` or `OMAKURE_SCRIPTS_DIR` with an explicit
  command.
- Removed the `theme` command, TOML theme configuration, built-in theme assets,
  Omarchy theme import, and theme-only dependencies.
- Removed directory `index.lua` widgets and the Lua widget runtime. `.lua` is
  not a supported script extension in this baseline.
- Release archives now contain exactly one root executable per platform:
  `omakure` on Linux/macOS or `omakure.exe` on Windows.

## Retained capabilities

- CLI commands for `run`, `doctor`, `scripts`, `describe`, `search`, `history`,
  `queue`, `battery`, `token`, `api`, `node serve`, `trace`, `help-ai`, `init`,
  `env`, `config`, `update`, `uninstall`, and `completion`.
- Stable JSON envelopes and error codes for AI-facing CLI operations and the
  HTTP API, including scoped token authentication and policy enforcement.
- HTTP health/readiness probes, script/catalogue routes, environment lifecycle,
  run history, queue workers, traces, Batteries, and metadata-only secret
  access according to the current API contract.
- Bash, PowerShell, and Python scripts with schema validation, environment
  injection, secret references and redaction, SQLite run state, and cron
  scheduling.
- `node serve` with optional queue workers and scheduler, readiness reporting, and
  graceful shutdown.

## Migration

- Replace positional or interactive invocations with explicit commands and
  `--scripts-dir PATH`.
- Replace TUI browsing and forms with `scripts`, `describe`, `init`, `run`,
  `queue`, `history`, or their HTTP operation equivalents.
- Move presentation settings out of Omakure and remove directory `index.lua`
  assumptions from workspaces.
- For deployment, run `node serve` and probe `/v1/health` and `/v1/ready`; see
  `.docs/headless-migration.md`, `.docs/headless-release.md`, and
  `.docs/release-artifacts.md` for the current contracts.

## Validation

- Same-target/profile local release measurement:
  `x86_64-unknown-linux-gnu`, Cargo default `release` profile,
  `omakure` 10,520,464 -> 8,815,352 bytes (-1,705,112; -16.21%).
- Direct normal dependencies decreased from 27 to 23 (`-4`).
- The version-only `v0.3.0` rebuild measured 8,812,016 bytes; its Linux archive
  measured 3,379,153 bytes and contained only the root `omakure` binary.
- Local `cargo test --all-targets --locked` passed with the certified suite and no
  failures; `mise run lint`, packaging smoke, node-service checks, formatting, and
  negative source/dependency/asset/help scans passed.
- The pre-version-bump certification archive measured 3,379,669 bytes and
  contained only the root `omakure` binary.
- Hosted Linux, macOS, and Windows CI/release runs remain pending and are not
  claimed by these local results.
